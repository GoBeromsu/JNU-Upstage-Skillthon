# examples/ — 데모용 견적서 이미지

이 폴더는 스킬을 체험·평가하기 위한 **샘플 견적서 이미지**만 포함한다.
런타임 파이프라인(`scripts/*.py`)은 이 폴더의 내용을 절대 참조하지 않으며,
오직 사용자가 명시적으로 경로를 지정해 입력할 때만 사용된다.

- `ray.png` — 기아 레이 (2015년식, 63,221km) 점검·정비 견적서
- `sportage.jpeg` — 기아 스포티지 (The SUV) 점검·정비 견적서 (102,672km)

사용법은 상위 `SKILL.md`의 "체험하기 (데모)" 섹션 참조.
